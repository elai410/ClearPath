# ClearPath

A hospital operating system: visit plans with slack, evidence as claims, and staff maps for doctors, nurses, and management — plus a patient view that says what they are waiting on, in their language.

The working tree is [`clearpath/`](./clearpath/). Start with [`clearpath/README.md`](./clearpath/README.md). The argument for what this has to become next is [`clearpath/HOSPITAL-OS-BEYOND.md`](./clearpath/HOSPITAL-OS-BEYOND.md).
